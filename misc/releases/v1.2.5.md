# Adaire Blocks v1.2.5 Release Notes

Version 1.2.5 introduces the **Horizontal Scroll Carousel** block family (Plus): a scroll-scrubbed horizontal track with nested card blocks, built with GSAP ScrollTrigger on the front end.

## Summary

This release adds a new two-block pattern—a **parent carousel** (`create-block/horizontal-scroll-carousel-block`) and a **child card** (`create-block/horizontal-scroll-card-block`)—registered under the `adaire-blocks-plus` category. Vertical scrolling drives horizontal translation of the track; the section is pinned while the scrubbed tween runs. Cards support rich layouts, media, shadow and border controls, responsive spacing, and an inner-blocks slot for **`create-block/button-block`**, **`core/buttons`**, and **`core/button`**.

## New Features / Improvements

### Horizontal Scroll Carousel (Plus)
- **Scroll-driven animation** – GSAP `ScrollTrigger` with `scrub` tied to scroll distance; pin at `start: 'center center'` so the strip engages when the section is centered in the viewport.
- **Dynamic scroll distance** – End position derived from the last card’s geometry relative to the section (including track padding) so the final card clears with consistent padding after load and refresh.
- **Resilience** – `invalidateOnRefresh`, `onRefreshInit` reset of track `x`, and image `load` handlers to re-measure when media changes dimensions.
- **Block controls** – `scrubSpeed`, `sectionBackground`, responsive padding, responsive card width/gap, responsive track horizontal padding, optional heading (text, size, color, weight).

### Horizontal Scroll Card
- **Inner block only** – `parent` restricted to the carousel; `inserter: false` so cards are added inside the carousel.
- **Content & layout** – Title and body (rich text where implemented), image ID/URL/alt, flex alignment and gap for card regions, responsive image width and card padding per breakpoint.
- **Styling** – Background, border radius, box-shadow controls, optional border, title/body color and typography.

### Configuration
- **`config/blocks-config.json`** – Feature flags and marketing-style feature tags for both blocks under the appropriate tier (Plus / `plus` and all-blocks sections).

## Technical Details

### Block registration
- **`src/horizontal-scroll-carousel-block/`** – `block.json` (API v3), `index.js`, `edit.js`, `save.js`, `style.scss`, `editor.scss`, **`view.js`** registered via `viewScript` for front-end behavior.
- **`src/horizontal-scroll-card-block/`** – `block.json`, `index.js`, `edit.js`, `save.js`, styles only (no view script; carousel drives layout).
- **`src/index.js`** – Imports both block entry points so they compile with the main bundle.

### Front-end (`view.js`)
- Registers ScrollTrigger with conservative refresh settings (`limitCallbacks`, `fastScrollEnd`, scoped `autoRefreshEvents`).
- Selects sections via `.adaire-hsc`, kills existing triggers on matching triggers to avoid duplicates on AJAX/navigation flows.
- Main tween: `gsap.to(track, { x: () => -getScrollDistance(), scrollTrigger: { pin, scrub: scrubSpeed, ... } })`.

### File Changes (high level)
- **adaire-blocks.php** – Version **1.2.5**.
- **src/horizontal-scroll-carousel-block/** – New block (including `view.js`).
- **src/horizontal-scroll-card-block/** – New nested card block.
- **src/index.js** – Registers new blocks.
- **config/blocks-config.json** – Enables and documents features for both blocks.

## Upgrade Impact

- **No breaking changes** for existing content; this release is additive.
- **Plus gating** – Ensure license / build flags expose Plus blocks if this should ship to paying sites only.
- **Assets** – Rebuild front-end assets so `view.js` and block scripts are available in `build/`.

## Backward Compatibility

- New block names and attributes only; no migration required for existing posts.
