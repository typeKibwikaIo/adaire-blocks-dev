# Adaire Blocks v1.2.5 – Horizontal Scroll Carousel (Plus)

## What's New

**Horizontal Scroll Carousel**  
A new **Plus** block adds a scroll-driven horizontal carousel: as visitors move down the page, the row of cards slides horizontally; scrolling up runs the motion in reverse. The section pins in the viewport so the effect feels intentional and smooth.

**Horizontal Scroll Card**  
Each slide is a **Horizontal Scroll Card** inside the carousel—title, description, optional image, and space for buttons (WordPress core or Adaire’s button block where available). You can style cards individually (colors, shadows, borders, spacing, and responsive image width).

**Editor controls**  
The carousel supports a section background, optional heading, responsive padding, card width and gap per breakpoint, horizontal track padding, and a **scrub speed** control to tune how tightly the animation follows scrolling.

## For Users

- **Plus only** – This block appears under the **Adaire Blocks Plus** category. Free sites will not see it unless they use a Plus-enabled build.
- **How to use** – Insert **Horizontal Scroll Carousel (Plus)**, then add or duplicate **Horizontal Scroll Card** blocks inside it. Adjust the carousel settings in the outer block and each card’s content in the inner blocks.
- **Performance** – The front end uses a scroll-linked animation library for reliable timing across devices; no manual carousel clicks required.

## Technical Summary

- New parent block: Horizontal Scroll Carousel (Plus), with a front-end view script for scroll-scrubbed horizontal motion.
- New child block: Horizontal Scroll Card (not shown in the inserter on its own; nested under the carousel).
